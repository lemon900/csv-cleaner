# CSV 命令行数据清洗工具

## 1. 项目简介

本项目使用 Python 标准库实现命令行 CSV 数据清洗，支持字符编码处理、缺失值检查、重复记录去除和非法值校验。

程序通过命令行参数指定输入文件及清洗规则，输出有效记录和被拒绝记录，适用于不同结构的小型 CSV 数据。

## 2. 运行环境

- Python：3.11.18
- 开发环境：PyCharm
- 依赖：Python 标准库，无须安装第三方库

## 3. 项目结构

- `clean.py`：命令行清洗程序
- `examples/input.csv`：原始测试数据
- `examples/input_bom.csv`：UTF-8 BOM 编码样例
- `examples/input_gb.csv`：GB18030 编码样例
- `tests/test_clean.py`：自动化测试
- `test_results.log`：测试运行记录

`output.csv` 和 `rejected.csv` 由程序运行时生成。

## 4. 功能说明

**编码处理**

支持 UTF-8、UTF-8 BOM 和 GB18030。默认优先尝试 UTF-8，失败后尝试 GB18030，也可以通过参数指定编码。输出统一为 UTF-8。

**缺失值处理**

对字段内容执行首尾空白清理。用户通过 `--required` 指定必填字段，必填字段为空时拒绝该记录。

**重复值处理**

默认按照整行去重，也可以使用 `--unique` 指定一个或多个去重字段。保留第一次出现的有效记录。

**非法值处理**

- `--integer`：整数类型检查
- `--range`：数值范围检查
- `--name-field`：姓名格式检查

姓名校验允许 Unicode 字母及间隔号 `·`，该规则仅用于本实验示例，不代表所有真实姓名的通用标准。

**拒绝记录**

不符合要求的记录写入 `rejected.csv`，并在 `error_reason` 字段中标明原因。

检查顺序为：必填字段 → 非法值 → 重复值。每条被拒绝的记录只计入一个主要类别。

## 5. 运行方法

在项目根目录的终端中执行：

`python clean.py --input examples/input.csv --output examples/output.csv --required name age --unique id --integer age --range age 0 120 --name-field name`

可以通过 `python clean.py --help` 查看全部参数。

默认在输出文件所在目录生成 `rejected.csv`。

## 6. 测试样例及结果

使用 19 条包含正常值、缺失值、重复主键和非法字段的记录进行验证。

| 结果 | 记录数 |
|---|---:|
| 原始记录 | 19 |
| 保留记录 | 7 |
| 缺失值拒绝 | 2 |
| 非法值拒绝 | 8 |
| 重复值拒绝 | 2 |

有效记录保存在 `output.csv`，其余 12 条记录及对应原因保存在 `rejected.csv`。

## 7. 退出码

| 退出码 | 含义 |
|---|---|
| 0 | 处理成功，无拒绝记录 |
| 1 | 处理完成，但存在拒绝记录 |
| 2 | 命令行参数或规则错误 |
| 3 | 输入文件或 CSV 格式错误 |
| 4 | 输出文件写入失败 |

## 8. 自动化测试

使用 Python 标准库 `unittest`。

运行命令：

`python -m unittest discover -s tests -v`

测试内容包括正常清洗、不同编码、非法值、去重顺序、文件不存在、CSV 格式异常、输入输出路径冲突和失败退出码等。

本地已完成 11 项自动化测试，运行记录保存在 `test_results.log` 中。

## 9. 边界处理与局限性

- 输入文件格式错误时，不直接覆盖原有输出。
- 使用临时文件写入结果，减少输出中断造成的不完整文件。
- 自动编码判断并不能保证识别所有原始编码。
- 两个输出文件分别替换，不能保证同时更新的原子性。
- 程序一次性读取输入数据，主要面向小型 CSV 文件。
- 姓名及数值检查依赖用户指定规则，不自动推断所有字段的业务含义。

## 10. 复现说明

项目仅依赖 Python 标准库。使用相同输入文件、参数和 Python 环境执行相同命令，可以复现对应的清洗结果。
